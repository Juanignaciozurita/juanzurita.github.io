# files/

Drop your PDFs here for self-hosting on the website (replacing the Google Drive links):

- CV (e.g. `cv.pdf`)
- Research Statement (e.g. `research-statement.pdf`)
- Teaching Statement (e.g. `teaching-statement.pdf`)
- Paper PDFs and slides (e.g. `bank-profit-channel.pdf`, `transmission-mechanism.pdf`, ...)

Filenames don't need to match these examples — once the files are here, Claude will detect them, rename sensibly if needed, and rewire all site links (Home, Research, CV pages) to point at them instead of Google Drive.

This folder IS published to the public site — do not put anything private here.
